# cert-practice-engine

Engine for an independent certification self-study site: domain drills, weighted
mock exams, weak-spot review and a readiness score, driven by one recipe per exam
and a bank of original, independently checked questions.

- Agent and contributor rules: [AGENTS.md](AGENTS.md)
- Architecture: [docs/proposals/0001-repo-structure-and-app-architecture.md](docs/proposals/0001-repo-structure-and-app-architecture.md)
- Content rules: [docs/content-rules.md](docs/content-rules.md)
- Automation runbooks: [docs/automation/](docs/automation/)

Exams: CISSP (recipe ready), AAIR (waiting on confirmed domain weights).

Not affiliated with, endorsed by, or sponsored by ISC2 or ISACA.

pnpm install
