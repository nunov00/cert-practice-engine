# Weekly steering digest

**Status: documented, not scheduled.** The app and sales sections apply once
the app is live.

One digest per week for the owner, short enough to read in five minutes.

## Contents

1. **Content:** PRs waiting for review, questions published this week,
   `pnpm coverage` totals per exam, checker reject rate per run.
2. **Quality:** new auto-flags and learner reports, each with a link to the
   proposed `fix/` PR or a note that one is needed.
3. **Outline watch and bank review:** any outline changes, and the quarterly
   review PR when one is open (`bank-review.md`).
4. **Sales and usage:** unlocks per exam, active learners, refunds.
5. **Proposed next week:** which generation runs are planned (exam, domain).

## Owner decisions it asks for

Merge or reject content PRs, approve fixes, change price or free sample size in
a recipe, start a new exam.
